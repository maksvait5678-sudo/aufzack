# AufZack

Статичний тренажер німецької граматики через інтервальне повторення.
Vanilla JS, ES-модулі, без бекенду й без збірки. Опис — у [SPEC.md](SPEC.md).

## Запуск

Відкрити `index.html` (хаб) або `play.html?topic=artikel` (гра). ES-модулі через `file://`
блокуються в Chrome/Firefox — для локального перегляду підняти сервер:

```
python3 -m http.server
```

На GitHub Pages працює як є. Тести: `node --test`.

## Що цей тренажер не вивчить

Чесно, щоб не створювати ілюзій:

- **продукцію в мовленні** — учень з 95% на картках у розмові все одно скаже
  `ein gute Mann`, бо там немає двох секунд на роздуми;
- **порядок слів** у складному реченні;
- **вибір прийменника** там, де можливі кілька (`nach` / `zu` / `in`);
- **дієслівне керування з прийменниками** (`warten auf`) — це лексика дієслова, окремий модуль.

Тренажер закриває автоматизм форм. Усе інше добирається розмовною практикою.
