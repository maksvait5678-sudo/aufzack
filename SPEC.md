# Deutsch Drill — специфікація проєкту

Статичний сайт для зубріння німецької граматики через інтервальне повторення.
Один рушій, багато тем. Без бекенду, без збірки, без залежностей.

Робоча версія першої теми вже існує (один HTML-файл, `legacy/artikel.html`).
Її треба не переписувати з нуля, а розібрати на рушій + дані.

---

## 1. Обмеження (не порушувати)

- Vanilla JS, ES-модулі, без фреймворків, без npm-залежностей у рантаймі, без збірки.
  GitHub Pages віддає репозиторій як є; `index.html` має працювати при відкритті напряму.
- Без бекенду і без акаунтів. Прогрес — `localStorage`.
- Працює офлайн після першого відкриття.
- Mobile-first, повне керування з клавіатури, темна і світла тема, `prefers-reduced-motion`.
- UI українською. Ідентифікатори в коді англійською.
- Ніякого трекінгу, аналітики, cookie-банерів.

## 3. Рушій інтервального повторення (не змінювати логіку)

Рівні 0..8, інтервали:

```
20 с · 1 хв · 10 хв · 1 день · 3 дні · 7 днів · 16 днів · 35 днів · 80 днів
```

Стан картки: `{ b: рівень, due: timestamp, r: правильних, w: помилок }`.

Оцінювання відповіді:
- **Помилка** → `b = 0`, `due = now + 20с`, серія обнуляється.
- **Правильно і швидко** (в межах ліміту типу картки) → `b = min(b+1, 8)`, `due = now + IV[b]`.
- **Правильно, але повільно** → `b = max(b, 1)`, рівень не росте, `due = now + IV[b]`.

Ліміти швидкості за типом картки: `choice` 4000 мс, `sentence` 7000 мс, `grid` 12000 мс, `type` 12000 мс.

Вибір наступної картки в режимі «Навчання», по порядку:
1. Прострочені картки, крім 3 останніх показаних; сортування: менший рівень → раніший `due`.
2. Нова картка, якщо карток у роботі (рівень ≤ 2) менше 6.
3. Дострокове повторення картки з рівнем ≤ 1, крім останніх показаних.
4. Нова картка, навіть якщо ліміт у роботі перевищено.
5. Найближча за `due` картка в роботі.

Режим «Профілактика»: випадкова картка з уже відкритих, вага
`1 + (6 - min(b,5))*2 + min(w,5)`. Правильна відповідь на не прострочену картку розкладу не змінює;
помилка діє як у звичайному режимі й повертає картку в чергу.

`srs.js` має бути чистою функцією від стану і часу, без DOM і без `Date.now()` всередині —
час приходить аргументом, щоб його можна було тестувати.

## 4. Типи карток

Тип — це контракт рендеру, а не тема.

- `choice` — запит і 6–8 варіантів-кнопок. Варіанти фіксованого порядку, гарячі клавіші 1..8.
- `sentence` — те саме, але запит це речення з пропуском; після відповіді пропуск заповнюється.
- `grid` — зворотна картка: показано відповідь, треба позначити всі клітинки матриці, де вона стоїть.
- `type` — ввід тексту з клавіатури. Порівняння без урахування регістру; умлаути приймати
  і в формі `ae/oe/ue/ss`. Потрібно для сильних дієслів.

Після помилки завжди показувати правильну відповідь і міні-таблицю теми з підсвіченою клітинкою.
Після правильної відповіді — автоперехід (швидка 750 мс, повільна 1500 мс).

## 5. Схема теми

```js
export default {
  id: 'artikel',
  title: 'Артиклі: der, die, das',
  subtitle: 'Відмінки і роди',
  answers: ['der','die','das','des','dem','den'],   // кнопки, фіксований порядок
  colors: { der:'#16C1E3', die:'#BDF45F', das:'#D3D6DE', des:'#FF6BCB', dem:'#FF6040', den:'#FFB957' },
  matrix: {                                          // для карти засвоєння і міні-таблиці
    rows: [{ k:'nom', label:'Nominativ', hint:'Wer? Was?' }, /* ... */],
    cols: [{ k:'m', label:'maskulin' }, /* ... */],
    value: (row, col) => 'der'
  },
  cards: [ /* згенеровані картки, у порядку введення нових */ ]
}
```

Картка: `{ id, type, prompt, answer, group, cell: {row, col} }`.
`cell` потрібна для карти засвоєння, у карток типу `grid` її немає.
`group` — назва блоку введення (наприклад `'Nominativ'`), показується в хабі.

Порядок карток у масиві = порядок відкриття нових. Тема сама вирішує послідовність.

## 6. Карта засвоєння

Матриця теми, заливка рівня — **нейтральний колір**, однаковий для всіх клітинок.
Кольори відповідей показуються тільки після натискання «Підглянути таблицю».
Це навмисно: кольорова карта дозволяє вчити візуально замість через питання.

## 7. Прогрес і міграція

```js
{ v: 2, topics: { artikel: { cards: {...}, streak, best, today } }, updatedAt }
```

Обовʼязково: при першому запуску прочитати старий ключ `artikel-srs-v1` і перенести його
в `topics.artikel`, старий ключ не видаляти. Прогрес не повинен губитися при оновленні сайту.

Додати експорт і імпорт прогресу одним текстовим кодом (base64 від JSON), кнопки в налаштуваннях.
Учні змінюють пристрої, і без цього вони втрачають усе.

## 8. Хаб (index.html)

Список тем: назва, коротке пояснення навіщо це вчити, відсоток засвоєння, скільки карток на черзі зараз.
Теми, що спираються на інші, позначені як рекомендовані після них, але не заблоковані.
Кнопка «Продовжити» веде в тему з найбільшою чергою.

## 9. Теми і порядок реалізації

Кожна тема — окремий PR. Наступну починати тільки після мержу попередньої.

**Фаза 1 — рефакторинг без нових функцій.**
Розібрати `legacy/artikel.html` на рушій + тему `artikel`. Поведінка, візуал і прогрес
мають лишитися ідентичними. Тести на `srs.js`. Це найважливіша фаза, не поспішати.

**Фаза 2 — `pronomen`. Особові займенники.**
Матриця: рядки Nominativ / Akkusativ / Dativ, колонки ich, du, er, sie, es, wir, ihr, sie/Sie.
Картки: пряма (Dativ + du → dir), зворотна (`grid` для ihm, ihr, uns, euch), речення
(Ich helfe ___ = dir/ihm/ihr). Відповідей більше шести — кнопки в два ряди, гарячі клавіші 1..9.

**Фаза 3 — `praepositionen`. Прийменники і відмінки.**
Три групи: тільки Akkusativ (durch, für, gegen, ohne, um, bis, entlang),
тільки Dativ (aus, bei, mit, nach, seit, von, zu, gegenüber),
Wechselpräpositionen (an, auf, hinter, in, neben, über, unter, vor, zwischen).
Картки: прийменник → відмінок; речення на Wo/Wohin з вибором артикля;
зворотна: показано «Dativ», позначити всі прийменники цієї групи.
Обовʼязково злити з темою артиклів: у реченнях відповідь — конкретний артикль, не назва відмінка.

**Фаза 4 — `ein_kein_mein`. Неозначений артикль, заперечення, присвійні.**
Та сама матриця, що в першій темі. Відповіді: ein, eine, einen, einem, einer, eines.
Окремий блок карток на паралель: «як der, тільки закінчення» — показати звʼязок явно,
бо це головна економія зусиль для учня.

**Фаза 5 — `verben_kasus`. Дієслова з Dativ і дієслова з прийменниками.**
helfen, danken, gefallen, gehören, passen, antworten, folgen + warten auf, denken an,
sich freuen über/auf, sprechen über/mit, bitten um. Тип карток `choice` і `sentence`.

**Фаза 6 — `starke_verben`. Сильні дієслова.**
fahren → fährt → fuhr → ist gefahren. Тип `type`, три поля по черзі, плюс вибір sein/haben.
Почати з 40 найчастіших, згрупованих за моделлю зміни голосної (a→ä→u, i→a→o, ei→ie→ie).

**Фаза 7 — `adjektive`. Відмінювання прикметників.**
Три схеми: після der-слів, після ein-слів, без артикля. Матриця 4×4 на кожну схему.
Найважча тема, братися тільки коли фази 1 і 4 повністю стабільні.

## 10. Правила щодо змісту

Німецькі дані — не імпровізація. Перед комітом теми звірити кожну форму з довідником
і винести дані в окремий файл, щоб їх міг перевірити вчитель. Якщо в якійсь формі є сумнів —
не вигадувати, а позначити `// TODO: перевірити` і сказати про це в описі PR.
Одна помилкова форма в грі про зубріння шкідливіша за відсутню тему.
